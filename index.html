02 / PROJECTS

Things I’ve built.

A couple of projects that show my interest in building practical and interactive web experiences.

PROJECT / 01

Canteen

A sample canteen website presenting a daily menu in a clear, easy-to-browse format. The menu is organized into Breakfast, Lunch, Snacks & Sides, and Beverages, with each item paired with a short description and listed price. Examples include avocado toast and blueberry pancakes for breakfast, quinoa salad and a grilled chicken wrap for lunch, plus snacks and cold drinks. The project demonstrates how a food menu can be arranged into a straightforward digital storefront for visitors to explore.

PROJECT / 02

Strength Protocol

A personalized fitness-tracking dashboard that helps users set a starting point and a target for an exercise, then follow a structured training progression. The setup lets users choose an exercise, current and goal reps, training days per week, and program length; the app displays the plan and tracks completed sessions and total reps. It also includes progress statistics, customizable workout days, exercise editing, and data import/export for backups. An optional AI Coach can be connected with a user-provided OpenRouter key, while the core tracker works without AI and stores plan data locally in the browser.
